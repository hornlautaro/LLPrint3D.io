Repositorio: sin configurar

Se detecta solo cuando la página está en usuario.github.io/repositorio.

¿Cómo consigo mi clave de acceso?
  1. Entrá a github.com/settings/personal-access-tokens/new con tu cuenta.
  2. Token name: “Admin LL Print 3D”. Expiration: elegí una fecha (por ejemplo, 1 año).
  3. Repository access: “Only select repositories” y elegí el repositorio de la página.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Apretá Generate token, copiá la clave (empieza con github_pat_) y pegala acá.

GitHub la muestra una sola vez: guardala en un lugar seguro. Si la perdés o vence, generás otra igual.
